# Guía de migración: 9.10.0 → 9.10.1

Osumi Framework **9.10.1** corrige una regresión en la emisión de códigos de estado HTTP establecidos mediante `OCore::setHttpStatus()`.

La actualización es compatible hacia atrás y no requiere modificar el código de las aplicaciones.

## Corrección

Desde la introducción del pipeline de Middlewares en 9.9, la respuesta HTTP final obtiene su código de estado desde el estado interno de `OMiddleware`.

Sin embargo, `OCore::setHttpStatus()` seguía actualizando únicamente el estado interno de `OCore`.

Esto podía producir una respuesta como:

```php
$core->setHttpStatus(404);
```

cuyo cuerpo correspondía al error esperado pero cuyo código HTTP emitido podía permanecer en `200`.

En 9.10.1, `OCore::setHttpStatus()` sincroniza también el estado HTTP gestionado por `OMiddleware`.

Los Middlewares ejecutados posteriormente siguen pudiendo sobrescribir el código HTTP de forma explícita.

## Migración

No es necesario modificar código de aplicación.

No existe un paso automático de migración para esta versión.
