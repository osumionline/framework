# Migrazio-gida: 9.9.0 → 9.9.1

**9.9.1** bertsioa mantentze-bertsio bat da, Osumi Framework 9.9.0 bertsioan sartutako migrazio automatikoen sistemako arazo bat zuzentzen duena.

9.9.0 bertsiotik 9.9.1 bertsiora eguneratzeko ez da aplikazioaren kodean aldaketarik egin behar.

---

## Laburpena

9.9.1 bertsioak Middleware faseen konstante natiboak erabiltzen dituzten ibilbideen detekzioa zuzentzen du:

```php
OMiddleware::PHASE_BEFORE
OMiddleware::PHASE_AFTER_RENDER
OMiddleware::PHASE_AFTER_RESPONSE
```

9.9.0 bertsioan, dagoeneko migratutako honelako ibilbide bat:

```php
ORoute::get(
    '/profile',
    ProfileComponent::class,
    [
        OMiddleware::PHASE_BEFORE => [
            LoginMiddleware::class
        ]
    ]
);
```

Filter legacy-en migrazioak gaizki interpreta zezakeen, oraindik Filter definizio bat balitz bezala.

Horrek honelako errore bat sor zezakeen:

```text
Legacy route contains a Filter expression that cannot be migrated automatically.
Use only ClassName::class entries.
```

9.9.1 bertsioak detekzio hori zuzentzen du, Middleware faseen konstante natiboak erabiltzen dituzten ibilbideak dagoeneko migratuta daudela identifikatzeko eta aldaketarik gabe mantentzeko.

---

## Aplikazioan egin beharreko aldaketak

Bat ere ez.

Ez dago:

- API aldaketarik;
- konfigurazio aldaketarik;
- datu-base aldaketarik;
- ibilbideetan egin beharreko aldaketarik;
- Middlewareetan egin beharreko aldaketarik;
- DTOetan egin beharreko aldaketarik.

9.9.0 bertsioarekin behar bezala funtzionatzen duten aplikazioak zuzenean 9.9.1 bertsiora egunera daitezke.

---

## Framework migrazioak

9.9.1 bertsioak **ez du migrazio-pauso berririk gehitzen**.

Azken migrazio-pausoa hau izaten jarraitzen du:

```text
9.9.0
```

Beraz, normala da Osumi Framework 9.9.1 erabiltzen duen aplikazio batek hau edukitzea:

```json
{
    "last_migrated": "9.9.0"
}
```

hemen:

```text
ofw/tmp/state.json
```

Egoerak exekutatutako azken migrazio-pausoa gordetzen du, ez derrigorrez instalatutako framework-aren bertsio zehatza.

9.9.1 zuzenean instalatzen duen proiektu berri batean, runner-ak hau exekuta dezake:

```text
0.0.0 → 9.9.1
```

eta lehendik dagoen `9.9.0` migrazio-pausoa aplikatu behar denean.

---

## Eguneratzea

Eguneratu framework-a normalean Composer bidez:

```bash
composer update osumionline/framework --with-dependencies
```

Ez da beste ekintzarik behar.
