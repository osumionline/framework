# Migrazio-gida: 9.12.0 → 9.12.1

Osumi Framework **9.12.1** bertsioak `CURRENT_TIMESTAMP` balio lehenetsi dinamiko gisa erabiltzeko euskarria gehitzen du `DATETIME` eremuetan.

Bertsio honek benetako datu-baseekin `generateModelFromDB` erabiltzean aurkitutako kasu bat zuzentzen du.

## CURRENT_TIMESTAMP

9.12.0 bertsioan, honelako SQL zutabe bat:

```sql
`joined_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
```

ezin zen ORM bidez irudikatu.

`generateModelFromDB` tresnak eremua `OField::DATETIME` gisa behar bezala detektatzen zuen, baina `CURRENT_TIMESTAMP` baztertzen zuen ORM-aren balio lehenetsiek balio literalak soilik onartzen zituztelako.

9.12.1 bertsiotik aurrera honela irudika daiteke:

```php
#[OField(
	type: OField::DATETIME,
	nullable: false,
	default: OField::CURRENT_TIMESTAMP
)]
public ?string $joined_at = null;
```

SQL eskema berriro sortzean, adierazpena mantentzen da:

```sql
`joined_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
```

## generateModelFromDB

`generateModelFromDB` tresnak MariaDB-k itzul ditzakeen bi ohiko formak ezagutzen ditu orain:

```text
CURRENT_TIMESTAMP
CURRENT_TIMESTAMP()
```

Biak honetara bihurtzen dira:

```php
default: OField::CURRENT_TIMESTAMP
```

Euskarri hori `OField::DATETIME` eremuetara mugatzen da esplizituki.

`UUID()` bezalako SQL adierazpen arbitrarioek ez dute euskarririk izaten jarraitzen, ORM-ak ezin baititu modu seguruan irudikatu.

## Balio literalak

`OField::CURRENT_TIMESTAMP` ORM-aren balio berezi bat da.

Ez da honelako testu literal batekin nahastu behar:

```php
default: 'CURRENT_TIMESTAMP'
```

Eduki hori duen string batek testu-balio arrunta izaten jarraitzen du eremu motak baimentzen duenean.

## Runtime

Modelo berri batek honelako `DATETIME` eremu bat duenean:

```php
default: OField::CURRENT_TIMESTAMP
```

ORM-ak uneko timestamp-era bihurtzen du:

```text
Y-m-d H:i:s
```

formatuan, erregistroa gorde aurretik balio lehenetsiak aplikatzen direnean.

## Migrazioa

9.12.1 bertsioak ez du migrazio automatikoko urrats berririk.

9.12.0 bertsioan dauden modeloek ez dute aldaketarik behar, datu-basean `CURRENT_TIMESTAMP` balio lehenetsia duen `DATETIME` zutabe bat irudikatzen ez badute.

Kasu horretan, `generateModelFromDB` tresnak definizioa behar bezala birsortu dezake orain.

## Eguneratzea

Eguneratu normalean Composer bidez:

```bash
composer update osumionline/framework --with-dependencies
```

Eguneratu ondoren berriro exekuta dezakezu:

```bash
php of generateModelFromDB
```
