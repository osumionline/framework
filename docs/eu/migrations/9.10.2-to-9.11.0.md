# Migrazio-gida: 9.10.2 → 9.11.0

Osumi Framework **9.11.0** bertsioak SQL `DECIMAL(p,s)` zutabeentzako ORM euskarri natiboa gehitzen du.

Eguneraketa atzerantz bateragarria da eta dauden modelo-definizioek ez dute aldaketarik behar.

## DECIMAL euskarria

`DECIMAL` eremuek `OField::DECIMAL` eta PHP `?string` propietateak erabiltzen dituzte.

```php
#[OField(
	type: OField::DECIMAL,
	precision: 12,
	scale: 2,
	nullable: false
)]
public ?string $amount = null;
```

`string` erabiltzeak bitarteko puntu mugikorreko bihurketak saihesten ditu eta balio hamartar zehatza mantentzen du.

`float` eta `int` balioak ez dira baliozkoak `DECIMAL` eremuetarako.

Lehenetsitako precision `10` da eta lehenetsitako scale `2`. Gehieneko precision `65` da eta gehieneko scale `30`.

`.` eta `,` onartzen dira sarrerako bereizle hamartar gisa. ORM-ak beti `.` eta scale finkoa erabiliz normalizatzen ditu balioak:

```text
"12"   → "12.00"
"12.5" → "12.50"
"12,5" → "12.50"
```

ORM-ak ez du biribiltze automatikorik egiten. Konfiguratutako precision edo scale gainditzen duten balioak baztertzen dira.

`OField::DECIMAL` ezin da `#[OPK]` eremuetan erabili.

## Kontsultak

`where()` eta `count()` metodoei emandako baldintzak modeloaren eskemaren arabera balidatu eta normalizatzen dira orain.

Adibidez, `DECIMAL(12,2)` eremu baterako:

```php
Payment::where([
	'amount' => '12,5'
]);
```

barnean `"12.50"` balioa erabiltzen da.

Eremu bererako puntu mugikorreko balioa baztertzen da:

```php
Payment::where([
	'amount' => 12.5
]);
```

Modeloan existitzen ez diren eremuak aipatzen dituzten baldintzak ere baztertzen dira.

## Sortzaileak

`generateModel`, `generateModelFrom` eta `generateModelFromDB` tresnek `DECIMAL` eremuak onartzen dituzte.

`generateModelFromDB` tresnak precision, scale eta balio lehenetsi hamartarrak kate zehatz gisa mantentzen ditu.

## PHP 8.5 bateragarritasuna

ORM eskemaren hasieratzeak `ReflectionProperty::hasDefaultValue()` egiaztatzen du orain `ReflectionProperty::getDefaultValue()` deitu aurretik, balio lehenetsi espliziturik gabeko propietateen PHP 8.5 deprecation abisua saihesteko.

## Migrazioa

Bertsio honek ez du migrazio automatikoko urratsik.

`OField::DECIMAL` erabiltzen ez duten proiektu existenteek ez dute modelorik aldatu behar.

`DECIMAL` erabiltzen hasten diren aplikazioek balio horiek kate zehatz gisa irudikatu behar dituzte eta `float` motara bihurtzea saihestu.
