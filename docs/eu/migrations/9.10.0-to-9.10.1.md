# Migrazio-gida: 9.10.0 → 9.10.1

Osumi Framework **9.10.1** bertsioak `OCore::setHttpStatus()` bidez ezarritako HTTP egoera-kodeen emisioari eragiten zion erregresio bat zuzentzen du.

Eguneraketa atzerantz bateragarria da eta ez du aplikazio-kodean aldaketarik behar.

## Zuzenketa

Middleware pipeline-a 9.9 bertsioan sartu zenetik, azken HTTP erantzunak `OMiddleware`-ren barneko erantzun-egoeratik hartzen du egoera-kodea.

Hala ere, `OCore::setHttpStatus()` metodoak `OCore`-ren barneko egoera baino ez zuen eguneratzen.

Horrek honelako kode batekin:

```php
$core->setHttpStatus(404);
```

esperotako errore-gorputza duen erantzuna sor zezakeen, baina bidalitako HTTP egoera-kodea `200` izaten jarrai zezakeen.

9.10.1 bertsioan, `OCore::setHttpStatus()` metodoak `OMiddleware`-k kudeatutako HTTP egoera ere sinkronizatzen du.

Pipeline-an geroago exekutatzen diren Middleware-ek egoera-kodea esplizituki gainidazteko aukera mantentzen dute.

## Migrazioa

Ez da aplikazio-kodea aldatu behar.

Bertsio honek ez du migrazio automatikoko urratsik.
