# Migrazio-gida: 9.8.3 → 9.8.4

**9.8.4** bertsioak HTTP egoera-kode baten zuzenketa eta bide-aurrizkien kudeaketan eta URLen normalizazioan hobekuntzak dakartza.

---

## Laburpena

### Gehitua

- Migrazio-gida hau.

### Aldatuak

- `getHttpStatus()` metodoak `401 Unauthorized` egoera ezagutzen du orain.
- `ORoute::prefix()` eta `ORoute::group()` metodoek habiaratzea onartzen dute orain.
- `ORoute` metodo estatikoen bidez erregistratutako URLak normalizatu egiten dira, barra bikoiztuak eta amaierako barrak kentzeko.

### Kenduak

- Ez da ezer kendu.

---

## Eragina lehendik dauden proiektuetan

- Ez da beharrezkoa lehendik dauden bideen definizioak aldatzea.
- Habiaratutako bide-aurrizkiek eta taldeek bide metatuak sortzen dituzte orain.
- Barra errepikatuak edo amaierako barrak dituzten bide-URLak modu uniformean normalizatzen dira.
- Ez da konfigurazioan, datu-basean edo CLIan aldaketarik behar.

Adibidez, aurrizki habiaratuekin:

```php
ORoute::prefix('/api', function(): void {
	ORoute::get('/health', HealthComponent::class);

	ORoute::prefix('/admin', function(): void {
		ORoute::post('/login', LoginComponent::class);
		ORoute::get('/me', MeComponent::class, [AdminAuthFilter::class]);
	});
});
```

Honako bide hauek erregistratzen dira:

- `/api/health`
- `/api/admin/login`
- `/api/admin/me`

Bide-URLak ere normalizatu egiten dira. Adibidez:

```php
ORoute::prefix('/api/', function(): void {
	ORoute::prefix('//admin///', function(): void {
		ORoute::get('//users/', UsersComponent::class);
	});
});
```

Bidea honela erregistratzen da:

- `/api/admin/users`

URLen normalizazioa `ORoute` metodo estatiko hauetan aplikatzen da: `get()`, `post()`, `put()`, `delete()`, `view()`, `group()` eta `prefix()`.

## Eguneratze honen helburua

Bertsio honen helburuak hauek dira:

- `401 Unauthorized` egoerarako HTTP egoera-kate zuzena itzultzea, `200 OK` egoerara jo beharrean.
- Habiaratutako bide-aurrizkiak eta taldeak onartzea, eta bide-URLak modu uniformean normalizatzea.

---

## Aurreko bertsioekiko bateragarritasuna

Lehendik dauden bideen definizioek bateragarriak izaten jarraitzen dute. Barra bikoiztuak edo amaierako barrak dituzten bide-URLak bide kanoniko bakar batera normalizatzen dira orain. Barra horiek esanguratsuak izatearen mende dauden aplikazioek bideen definizioak berrikusi beharko lituzkete.

---

## Garatzaileak egin beharrekoa

Ohiko aplikazioetan ez da ezer egin behar. Barra bikoiztuak edo amaierako barrak erabiltzean oinarritzen diren bideen definizioak berrikusi.

---

## Oharrak

Ez da datu-basearen migraziorik behar.
