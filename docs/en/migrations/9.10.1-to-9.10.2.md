# Migration Guide: 9.10.1 → 9.10.2

Osumi Framework **9.10.2** fixes ORM parameter binding so scalar values are sent to PDO using their appropriate parameter types.

The update is backward compatible and does not require changes to application code.

## Fix

Until 9.10.1, parameterized ORM operations passed their parameter arrays directly to `PDOStatement::execute()`.

This could cause boolean values such as:

```php
$model->active = false;
$model->save();
```

to be sent by PDO as strings. In MySQL/MariaDB strict mode, `false` could therefore reach a `TINYINT(1)` column as an empty string and produce an error such as:

```text
Incorrect integer value: '' for column 'active'
```

In 9.10.2, `OModel` binds statement parameters explicitly before execution:

- `bool` values use `PDO::PARAM_BOOL`.
- `int` values use `PDO::PARAM_INT`.
- `null` values use `PDO::PARAM_NULL`.
- Other supported scalar values use `PDO::PARAM_STR`.

The fix applies consistently to parameterized ORM reads and writes, including queries, counts, inserts, updates and deletes.

## Migration

No application code changes are required.

Existing model definitions and boolean assignments remain valid:

```php
$model->active = false;
$model->save();
```

There is no automatic migration step for this release.
