# Migration Guide: 9.10.0 → 9.10.1

Osumi Framework **9.10.1** fixes a regression affecting HTTP status codes set through `OCore::setHttpStatus()`.

The update is backward compatible and does not require changes to application code.

## Fix

Since the Middleware pipeline was introduced in 9.9, the final HTTP response obtains its status code from the internal `OMiddleware` response state.

However, `OCore::setHttpStatus()` was still updating only the internal `OCore` state.

This could produce a response such as:

```php
$core->setHttpStatus(404);
```

whose body represented the expected error while the emitted HTTP status could remain `200`.

In 9.10.1, `OCore::setHttpStatus()` also synchronizes the HTTP status managed by `OMiddleware`.

Middlewares executed later in the pipeline can still explicitly override the status code.

## Migration

No application code changes are required.

There is no automatic migration step for this release.
